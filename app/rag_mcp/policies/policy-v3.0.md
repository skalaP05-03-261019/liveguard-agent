# AI 실시간 채팅 관제 운영정책 v3.0

선택: 손세원

# 제1장. 기본 원칙

## CP-1.1 적용 대상과 목적

본 정책은 라이브 방송 시청자의 공개 채팅에 적용한다. 이용자의 정상적인 의견 표현을 보장하면서 욕설, 괴롭힘, 도배, 피싱, 개인정보 노출로 발생하는 피해를 예방하는 것을 목적으로 한다.

## CP-1.2 판단 원칙

- 위반 여부는 위반 유형, 표현의 맥락, 반복성, 위험성, 확정된 제재 이력을 종합해 판단하고 비례적으로 조치한다.
- 특정 단어가 포함되었다는 이유만으로 위반을 확정하지 않는다. 단, CP-2.1의 욕설 키워드는 예외로 한다.
- 자동 조치의 **명백함**은 모델의 확신도 수치가 아니라 실제 금지 조건의 근거, 정상 예외 검토, 정책 버전 일치, 서버 검증 통과를 모두 충족한 상태를 말한다.
- 근거가 부족하거나 서로 충돌하면 `NEEDS_REVIEW`로 판정하고 신규 확정 제재를 하지 않는다.
- 본 정책의 위험 유형은 `PROFANITY`, `HARASSMENT`, `FLOOD`, `PHISHING`, `PII_EXPOSURE` 5개다. 하나의 메시지가 욕설과 괴롭힘에 동시에 해당할 수 있으며, 이 경우 메시지 숨김은 한 번만 적용하고 이력의 유형은 각각 기록한다.

# 제2장. 위험 유형

## CP-2.1 욕설 (PROFANITY)

- 욕설 사전에 등록된 확실한 욕설 키워드가 포함된 메시지는 대상이나 문맥과 관계없이 위반으로 본다.
- 사전에 등록되지 않은 비하 표현이나 변형 표현은 위반으로 확정하지 않는다. 공개를 유지한 채 Agent가 문맥을 근거로 판단하며, 특정 대상을 비방하거나 모욕하면 CP-3.1과 CP-3.2를 적용한다.

## CP-2.2 인용·설명·제지 및 오탐 예외

다음은 특정 단어가 포함되어 있어도 위반으로 보지 않는다. 단, CP-2.1의 욕설 키워드가 포함된 메시지에는 이 예외를 적용하지 않는다.

1. 혐오 발언이나 욕설을 비판·설명하기 위한 최소한의 인용
2. 다른 이용자의 위반 행위를 제지하는 발언
3. 게임 플레이나 방송 내용에 대한 일반적인 비판·불만
4. 특정 개인을 공격하지 않는 감탄이나 일상적인 구어체 표현
5. 게임 속 전투·공격·처치 등의 표현
6. 동의된 상황의 가벼운 농담이나 시청자 간 일상 대화
7. 객관적인 비판, 반대 의견, 질문 등 정상적인 의사 표현

풍자, 인용, 농담 여부나 특정 대상에 대한 공격 여부가 불분명하면 `NEEDS_REVIEW`로 판정한다.

## CP-3.1 인신공격의 판단 범위

인신공격은 욕설을 제외한 모든 부정적 뉘앙스를 뜻하지 않는다. 일반적인 비판, 긍정적 과장, 공격 대상을 추정만 할 수 있는 표현으로는 위반을 확정하지 않는다.

## CP-3.2 괴롭힘 (HARASSMENT)

식별 가능한 특정 대상을 향해 인격을 비하하거나 모욕하는 인신공격, 또는 같은 대상을 반복적으로 괴롭히는 행위를 위반으로 본다. 대상과 공격 표현이 모두 확인되어야 한다.

## CP-4.1 도배 (FLOOD)

- 같은 작성자가 같은 채널에서 10초 안에 정규화 결과가 같은 메시지를 3개 이상 보내면 도배로 조사하고, 세 번째 메시지부터 임시 비노출한다.
- 정규화 규칙은 `norm-v1`이다: 유니코드 NFKC, 소문자 변환, 공백 축약, 같은 글자가 3회 이상 반복되면 2회로 줄임. 의미 유사도는 사용하지 않는다.
- 서로 다른 작성자의 같은 응원 메시지는 합산하지 않는다.
- 같은 `clientMessageId`로 재전송된 메시지는 1건으로 센다.

## CP-5.1 피싱·사칭 (PHISHING)

운영자나 관리자를 사칭해 허위 공지를 하거나, 시청자에게 인증정보·개인정보·금전을 요구하거나, 사기 목적의 링크로 유도하는 행위를 위반으로 본다. 허용되지 않은 반복 홍보도 여기에 포함한다.

- 메시지에 URL이 포함되었다는 이유만으로 확정하지 않는다.
- 링크의 공식 여부는 SP-2.1에 따라 서버가 확인한 결과를 사용한다.
- 서버가 확인할 수 없는 사실이 판단에 필요하면 `NEEDS_REVIEW`로 판정한다.

## SP-2.1 공식 링크 검증

공식 도메인 여부는 Backend가 URL을 파싱해 정규화한 호스트를 등록된 공식 호스트와 **정확히 비교**해 판단한다. 부분 문자열 포함 여부로 판단하지 않는다. Agent는 서버가 제공한 `isOfficial` 결과를 근거로 사용한다.

## SP-3.1 개인정보 노출 (PII_EXPOSURE)

타인의 비공개 실명, 주소, 연락처, 계정정보 등을 동의 없이 공개하거나 공개를 유도하는 행위를 위반으로 본다.

- 전화번호나 계좌번호 형태의 정규식 검출만으로 위반을 확정하지 않는다. 패턴 검출은 위험 후보 선정, 마스킹, 임시 비노출의 근거로만 쓴다.
- 정보의 실재 여부나 공식 안내 번호 여부 등 사실 확인 결과가 `UNKNOWN`이면 자동 확정 제재보다 사람 검토를 우선한다.
- 즉각적인 피해가 우려되면 판정 중에도 메시지를 임시 비노출할 수 있다.

## CP-6.1 정의된 유형 밖의 위험

구체적인 혐오·차별, 성희롱 등 성적 위해, 신체적 위협은 본 버전에서 독립 유형으로 자동 추가하지 않는다. 동시에 유형 밖이라는 이유로 정상으로 확정하는 것도 금지한다. 이러한 메시지는 `NEEDS_REVIEW`로 판정해 운영자 검토로 넘긴다.

# 제3장. 판정과 노출 상태

## MP-1.1 상태 구분

판정과 노출 상태는 서로 다른 값이며 같은 의미로 쓰지 않는다.

| 구분 | 값 | 의미 |
| --- | --- | --- |
| 초기 필터 | `PASS`, `REVIEW`, `HOLD`, `FLOOD` | 조사 후보 선정과 초기 노출 처리 |
| Agent 판정 | `NO_VIOLATION`, `VIOLATION`, `NEEDS_REVIEW` | 정책 위반 여부 판단 |
| 노출 상태 | `PUBLIC`, `HELD`, `HIDDEN` | 시청자에게 보이는 상태 |

## MP-1.2 상황별 처리 기준

| 상황 | 처리 기준 |
| --- | --- |
| 정상이고 PUBLIC | 그대로 공개하고 변경하지 않는다. |
| 정상이고 HELD | 해당 사건이 건 임시 비노출만 해제한다. 다른 사유의 임시 비노출이나 숨김이 남아 있으면 공개하지 않는다. |
| 위반 확정 | Backend가 최신 증거, 정책 버전, 권한, 현재 상태를 검증한 뒤 제4장의 조치를 실행한다. |
| 근거 부족 또는 충돌 | `NEEDS_REVIEW`로 판정하고 신규 확정 제재를 하지 않는다. |
| 검토 필요이고 PUBLIC | 검토가 필요하다는 이유만으로 숨기지 않는다. |
| 검토 필요이고 HELD | 현재 임시 비노출을 유지하고 운영자에게 검토 대상으로 표시한다. |

# 제4장. 제재 기준

## MP-2.1 제재 기준표

제재는 위반 유형과 직전 30일의 확정 위반 건수(MP-3.1)로 정한다. `TIMEOUT` 기간 단위는 초다. 600초는 10분, 86400초는 1일, 604800초는 7일이다.

| 유형 | 이전 확정 0건 | 이전 확정 1건 | 이전 확정 2건 이상 |
| --- | --- | --- | --- |
| `PROFANITY` | HIDE | HIDE + TIMEOUT 600초 | HIDE + TIMEOUT 86400초 |
| `HARASSMENT` | HIDE + TIMEOUT 600초 | HIDE + TIMEOUT 86400초 | HIDE + TIMEOUT 604800초 |
| `FLOOD` | 세 번째 이후 중복 메시지 HIDE | 중복 HIDE + TIMEOUT 600초 | 중복 HIDE + TIMEOUT 86400초 |
| `PHISHING` | HIDE + TIMEOUT 86400초 | HIDE + TIMEOUT 604800초 | HIDE + TIMEOUT 604800초 |
| `PII_EXPOSURE` | HIDE | HIDE | HIDE + TIMEOUT 600초 |

모든 기간과 횟수는 본 프로젝트의 자체 정책 기준이며 실제 플랫폼의 공식 제재 기준이 아니다.

## MP-2.2 동시 위반

- 하나의 메시지에 여러 유형이 해당해도 HIDE는 한 번만 적용한다.
- TIMEOUT 후보가 여러 개면 가장 긴 하나만 적용하고 기간을 합산하지 않는다.

## MP-2.3 판단과 집행의 책임

Agent는 위반 유형, 근거 메시지, 정책 조항 ID를 반환한다. 제재 기간은 Agent가 정하지 않는다. Backend가 위반 이력, 기간, 현재 상태, 대상, 인증·인가를 검증하고 제재를 계산·실행한다.

## MP-3.1 위반 이력 집계

- 같은 채널·사용자·유형에서 직전 30일 동안 **확정되고, 취소되지 않았으며, 처리가 완료된** 위반만 센다.
- 다음은 집계하지 않는다: 현재 사건, 신고만 있는 사건, 임시 비노출, 취소된 위반, 도구 재시도 횟수.
- 한 번의 연속된 행위에서 나온 여러 메시지는 하나의 위반으로 센다.

## MP-3.2 이번 버전의 제외 범위

영구 제재, 30일 이상의 활동 제한, 횟수만으로 제재를 자동 확정하는 규칙은 본 버전에 포함하지 않는다. 강퇴는 MP-4.1에 따라 운영자 승인을 거쳐서만 실행한다.

## MP-4.1 강퇴 심사

- **집계 대상:** 같은 사용자가 같은 채널에서 받은 Backend 확정 위반을 5개 위험 유형 구분 없이 합산한다.
- **1건의 의미:** 서로 다른 위반 사건 1개를 1건으로 센다. 하나의 사건이 욕설과 괴롭힘에 동시에 해당해도 1건이다.
- **심사 조건:** 최근 24시간 동안 현재 사건을 포함해 3건 이상이면 운영자에게 강퇴 승인을 요청한다. 예를 들어 이전 확정 사건 2건과 현재 확정 사건 1건이면 3건이다.
- **제외:** 오판으로 취소된 위반, 이미 강퇴 심사에 사용된 위반, 근거가 불충분해 `NEEDS_REVIEW`로 판정된 사건은 합산하지 않는다.
- **해제의 의미:** 위반 판정의 취소와 채팅 제한 시간의 만료는 다르다. 채팅 제한 시간이 끝났다는 이유만으로 위반 이력이 사라지지 않는다.
- **승인 필수:** 강퇴는 자동으로 실행하지 않는다. Agent는 강퇴 심사를 요청하고 운영자의 결정을 기다린다. 운영자에게는 대상 메시지와 주변 대화, 위반 유형과 정책 근거, 판단 이유, 심사에 사용된 위반 목록을 제공한다.
- **승인:** Backend가 실행 직전에 심사 조건과 승인의 유효성을 다시 검증한 뒤 강퇴를 실행한다. 같은 승인으로 강퇴를 두 번 실행하지 않는다.
- **강퇴 효과:** 대상 사용자는 현재 방송에서 퇴장되며, 해당 방송이 끝날 때까지 다시 입장하거나 채팅할 수 없다.
- **거절:** 강퇴하지 않고 기존의 숨김과 채팅 제한은 유지한다. 심사에 사용된 위반 ID를 기록해 같은 위반으로 강퇴 심사를 반복 요청하지 않는다.

# 제5장. 개인정보 처리

## SP-4.1 원문 보호와 마스킹

- 모델 입력, 작업 대기열, 일반 로그에는 전화번호, 계정, 인증정보 등 불필요한 원문을 전달하지 않는다.
- 개인정보가 포함된 원문은 담당 운영자 이외의 화면에서 마스킹해 제공하고 보존 기간과 접근 권한을 제한한다.
- 비노출 상태의 원문은 일반 시청자에게 어떤 경로로도 전달하지 않는다.

# 제6장. 사후 검토와 복구

## MM-1.1 판단 기록과 후보고

Agent는 위반 정책 조항 ID, 대상 메시지, 판단 근거, 정책 버전을 기록한다. 자동 조치가 실행되면 운영자에게 결과를 보고하고, 제재 대상자에게는 조치 사유, 기간, 이의제기 경로를 안내한다.

## MM-2.1 이의제기 결정

| 결정 | 의미 | 결과 |
| --- | --- | --- |
| `UPHOLD` | 기존 위반 판단 유지 | 조치를 유지한다. 중복 집행이나 기간 연장은 없다. |
| `REVOKE_FINDING` | 잘못된 위반 판단 취소 | 해당 위반을 이력 집계에서 제외하고, 그 위반으로 생긴 숨김과 채팅 제한만 복구한다. |
| `REDUCE_ACTION` | 위반은 맞지만 제재가 과함 | 기간을 줄이거나 해제한다. |

다른 사건 때문에 숨겨진 메시지는 이의제기 취소로 자동 공개하지 않는다. 운영자는 잘못된 제재 사례를 오탐 평가 데이터로 활용할 수 있다.

# 제7장. 적용 우선순위

## CP-7.1 정책 간 우선순위

1. 플랫폼 공식 약관과 상위 운영정책
2. 본 채팅 운영정책
3. 개별 방송 채널이 사전에 고지한 추가 채팅 규칙

채널별 규칙은 상위 정책을 위반하거나 정당한 의견 표현을 부당하게 제한하도록 적용하지 않는다.
