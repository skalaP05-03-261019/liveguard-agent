## 시장조사 PDF (실제 1~3쪽)

- 프로필·사람 검토·요약 자체보다 한국어 우회 혐오 대응과 고객사 정책 조항 기반 설명을 차별화 후보로 제안합니다.
- 자체 관제팀이 없는 라이브 서비스·라이브커머스를 고객 가설로 제시하나 수요 통계·사례의 공백을 밝힙니다.
- 경쟁사의 가격·기능·한국어 지원, 뉴스 댓글 연구의 라이브 채팅 적용은 추가 공식 출처 확인이 필요합니다.
- 자료에서 기능을 찾지 못했다는 사실을 실제 미지원이나 기능 부재로 바꾸지 않습니다.

## 역할별 팀 작업 정리 HTML

- AI 요약 기술 구현은 진행하고 사용 역할·제공 시점은 추후 결정합니다.
- 방송별 설정은 레벨형·항목형·자연어형을 비교·협의합니다. 3단계를 최종 정책으로 확정하지 않습니다.
- 커뮤니티 은어는 수집 조건·출처·문맥·개인정보를 검토할 조사 예정 항목입니다.
- 외부 플랫폼 연동은 방향 검토이며 실제 연동 완료가 아닙니다.
- P0/P1 체크리스트는 논의용이고 작업 완료·담당자 확정의 증거가 아닙니다.
