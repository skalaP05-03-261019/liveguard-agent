# 후보 근거 메시지 참조 (#99)

로컬 채팅 데모에서 모델이 근거마다 채팅 원문을 다시 출력하면, 맞는 메시지를 선택해도 조사 문장을 의역하거나 긴 본문을 잘못 복사해 `MODEL_RESPONSE_REJECTED`가 날 수 있다. 모델 도구 입력은 `messageId` 참조만 요구한다. Agent는 제공받은 TARGET·CONTEXT에서 해당 ID의 **정확한 원문**을 채워 기존 `Assessment`와 공개 응답의 `evidence.text` 계약을 보존한다.

참조가 입력에 없거나 TARGET 근거가 없으면 여전히 실패한다. 모델이 임의로 `text`를 보낸 경우 서버는 덮어쓰지 않고 기존 근거 검증에서 원문 일치를 요구한다. 결과 유형·강도·이유는 그대로 모델이 제시하므로, 이 변경은 탐지 정확도 향상을 보장하지 않는다. BE 후보 전달·정책·운영자 승인·조치 경로는 변경하지 않는다.

검증: 전체 통제 테스트 462개 통과(환경 의존 97개 건너뜀). 같은 네 개발용 문장을 기존 로컬 데모와 변경 이미지에 각각 1회 입력한 실모델 smoke에서 양쪽 모두 HTTP 200이었다. 짧은 공격 의심·변형 욕설·인용 반박은 두 버전 모두 후보였고, 정치 문맥 사례는 기존 후보/변경 비후보로 달랐다. 인용 반박 후보는 오탐 의심 사례로 남는다. 이번 4회 실행으로 형식 실패율·탐지율·속도 개선을 주장하지 않는다. 팀 정책·QA 확인셋으로 별도 검증이 필요하다.
