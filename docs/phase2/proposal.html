01

고객사는 기준을 정하고, 이용자는 대화를 파악합니다

최초 작성 2026.10.21 · 내용 개정 2026.10.22 · 팀 자료 반영 v2.1 · 요약 개발 진행 / 이용 역할 미정 · 프로필·정책 세부는 협의

욕설이 직접 없어도 집단 혐오·지역비하·배제·반복 조롱을 조사 대상으로 발견하고, 고객사가 검토 범위를 선택하게 합니다. 채팅 요약은 기술 구현을 진행하며 스트리머·시청자 중 이용 역할과 표시 시점은 추후 결정합니다.

B2B / CUSTOMER & OPERATOR

자기 서비스에 맞는 채팅 관제

운영 기준을 선택하고, AI가 찾은 표현·대상·문맥·정책 근거를 확인해 최종 판단합니다.

SUMMARY / TARGET ROLE TBD

필요한 구간의 대화 흐름 파악

스트리머의 대화 점검 또는 시청자의 이전 대화 확인에 활용할 수 있습니다. 이용 역할·표시 위치는 미정이며 영상·음성 요약은 아닙니다.

검출은 목표이며 보장된 성능이 아닙니다UnSmile은 평가·개선의 출발점입니다. 데이터를 넣는 것만으로 모든 실시간 혐오를 검출할 수는 없습니다. 후보 전달, 스트리밍 문맥, 정상 발언 보호, 지연·비용을 함께 측정합니다. 아직 이번 Phase 2의 측정 결과는 없습니다.
팀 시장조사 반영 · 차별화 가설공유 시장조사는 프로필·사람 검토·요약 자체보다 한국어 우회 혐오 대응과 고객사 정책 조항에 근거한 설명을 차별화 후보로 제안합니다. 자체 관제팀이 없는 라이브 서비스·라이브커머스는 고객 가설이며 수요 증거는 보강이 필요합니다. 경쟁사의 기능 부재·한국어 미지원·가격을 검증된 사실로 단정하지 않습니다. 고객사 정책 문서 등록·승인·색인 격리는 추가 설계 범위이며 현재 구현 완료 기능이 아닙니다. 팀 조사 원문 1~3쪽

03

실시간 검출의 시작은 후보가 Agent에 도달하는 것입니다

현재 설계에서 PASS는 Agent 미호출입니다. 욕설 없는 혐오가 PASS로 끝나면 조사 프롬프트만 바꿔도 화면의 검출은 늘어나지 않습니다. BE 담당자와 추가 후보의 진입 지점·시간 제한·실패 처리를 먼저 합의합니다.

BE / 공통 규칙

기존 확정 규칙 유지

명확한 금지 욕설·링크 등 기존 확정 경로는 보존합니다. 완화 프로필도 공통 금지를 해제하지 않습니다.

→
BE ↔ AGENT / 후보 판별

프로필별 조사 후보 선정

나머지 메시지를 짧은 문맥·고객사 프로필로 판별합니다. 경량 분류 신호와 필요 시 AI 조사를 비교합니다.

→
BE → AGENT → HUMAN

사건·근거·사람 결정

BE가 HELD·사건을 생성하고 Agent가 조사합니다. 운영자 결정 후 BE가 실제 조치를 검증·집행합니다.

추가 후보 없음 → 기존 공개 흐름 / 후보 있음 → 기존 CONTEXT 검토 경로. 공개 전 호출과 timeout 시 동작은 팀 합의 후 적용하며, 이미 공개한 메시지의 뒤늦은 탐지는 별도 지표로 보고합니다.

경계합의할 최소 정보

후보 결과후보 여부·위험 신호 라벨·문제 표현·근거 messageId·미확인 사실·소요 시간. 후보 결과는 위반 확정/제재 명령이 아님
실시간 실행호출 timeout·큐 한도·재시도 상한·중복 방지·과부하 시 상태. 실패를 정상 판정으로 바꾸지 않음. 노출 정책은 BE 합의
범위 격리프로필·채팅·문맥·요약 캐시를 고객사/방송/공개 범위로 제한. 클라이언트가 고객사 식별자를 조작해도 서버 권한 검증
기존 시스템 보존사건·snapshot 정본화와 제재는 BE 담당. 기존 진행 이슈의 현재 상태는 팀과 확인하고 중복 구현하지 않음
실시간이라는 주장은 부하 시험 후에만 사용합니다수신→후보 결정, 수신→검토 카드 도착 지연을 각각 잽니다. 입력률·동시 방송 수·처리 장비·대기열·누락/오류를 기록합니다. 통합 전 오프라인 성공을 실시간 서비스 완료로 제시하지 않습니다.
04

검토 강도를 선택하고, 같은 채팅에서 비교합니다

설정 방식은 레벨형·항목형·자연어형을 비교·협의 중입니다. 아래 3단계는 레벨형의 제안 예시이며 확정된 UI가 아닙니다. 초기안은 공통 금지 정책을 유지하고 추가 조사 후보의 범위를 조절하는 방식입니다. 위반 정의·제재 강도를 고객사가 바꾸는 기능은 별도 정책 합의로 둡니다. 프로필은 고객사 권한자가 저장하고 버전·변경 이력을 남깁니다.

프로필 제안추가 조사 범위선택 시 함께 볼 지표
완화형추가 의미 탐지에서 공격·비하가 명확한 후보 중심검토량 감소와 위반 누락 여부
균형형우회 비하·배제·특정 대상 공격 신호까지 조사유형별 누락·오탐·검토량 균형
엄격형더 약하거나 모호한 조롱·고정관념 신호도 검토 후보로 확대추가 검토량·정상 발언 오탐·운영자 처리 부담

프로필별 유형 활성화와 임계값은 검수된 개발셋에서 정합니다. 분류 점수·LLM 자기 확신을 보정 없이 “위반 확률 80%”로 표시하지 않습니다. 최종 확인셋을 보고 임계값을 재조정하지 않습니다.

균형형 · 우회 비하와 표적 공격까지 조사

직접 작성한 6개 사례의 고정 시나리오입니다. 실제 AI 호출·임계값 계산·성능 측정·설정 저장은 하지 않습니다.

지역·집단을 언급했다는 이유만으로 후보를 만들지 않습니다. 후보로 표시돼도 위반은 미확정이며, 주변 대화와 대상·인용 여부를 확인합니다.

설정 변경은 진행 중인 사건을 몰래 바꾸지 않습니다판단 당시 정책/프로필 버전을 사건과 평가 결과에 기록합니다. 변경은 원칙적으로 이후 입력부터 적용하는 안을 제안하며, 과거 사건 재평가 여부는 별도 결정합니다. 미리보기는 실제 숨김·제재 없이 실행합니다.
05

문제 표현보다 대상과 맥락을 함께 설명합니다

모든 발언은 직접 작성한 설계 사례입니다. 데이터셋 원문이나 실제 모델 결과가 아닙니다. 새 집단 혐오 유형은 정책·계약 확장 합의 전까지 기존 HARASSMENT에 억지로 편입하지 않습니다.
